# FreeNotes — legal and support website

Static pages for the FreeNotes iPhone app, published with GitHub Pages:

- Home: https://ekkacaffle-dot.github.io/FreeNotes-Legal/
- Privacy Policy: https://ekkacaffle-dot.github.io/FreeNotes-Legal/privacy.html
- Terms & Conditions: https://ekkacaffle-dot.github.io/FreeNotes-Legal/terms.html
- Support: https://ekkacaffle-dot.github.io/FreeNotes-Legal/support.html

This repository contains only these website files. They are generated from the app project (`tools/legal/generate.py`), which also produces the identical in-app copies that work offline; edit the text there, regenerate, and copy the `legal-site/` folder here.

No scripts, external fonts, analytics or trackers. Contact: ekka.caffle@gmail.com.
